# CASEFILE: Forensic Division

Pixel-art inspired fictional forensic investigation game for GitHub Pages.

Includes progressive cases, police reports, suspect statements, evidence locker, process-one/process-all workflow, 20-reference fingerprint matching, simulated DNA comparison, simulated firearm/casing mark comparison, simulated authorized phone forensic extraction, case board, final filing, scoring, XP, levels and local saves.

## Publish
Upload the files to a GitHub repository, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

All evidence, profiles, firearm marks and phone data are fictional. The phone tool is a simulated game interface and is not a real-world hacking tool.
